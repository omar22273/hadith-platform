# منصة الحديث النبوي والتاريخ الإسلامي التفاعلية

تطبيق Flutter يقدّم الأربعين النووية وِرداً يومياً على مسار قوافل تاريخي. فيه ثلاث شاشات:

- **مسار القوافل:** طريق متعرج على هيئة S، يحمل محطات مكتملة ونشطة ومقفلة حتى يحين وِردها، وتسير عليه القافلة.
- **الوِرد اليومي:** أربع مراحل، هي السياق، فالمتن والغريب، فالتثبيت الحركي، فالإسقاط السلوكي. ومعها طبقة طالب العلم، وقفل الفجر في الختام.
- **مجلس السماع والمشافهة:** لكبار السن ولمن يفضّل التلقي الشفاهي.

## التشغيل

المتطلبات: Flutter بإصدار يحمل Dart 3.12 أو أحدث.

```bash
git clone <المستودع> && cd hadith_platform
flutter create --platforms=android,ios --org app.hadithplatform .   # يولّد مجلدي المنصتين ولا يمس lib/
flutter pub get
flutter test
flutter run
```

**أندرويد (للصوت الآلي في وضع السماع):** أضف هذا الوسم داخل `<manifest>` في `android/app/src/main/AndroidManifest.xml`، وإلا لم يجد Android 11 فما بعده محرك الكلام:

```xml
<queries>
  <intent>
    <action android:name="android.intent.action.TTS_SERVICE" />
  </intent>
</queries>
```

**محرك الرسم:** Impeller هو الافتراضي على iOS وAndroid في إصدارات Flutter الحالية.

## المعمارية (Feature-First Clean Architecture)

```
lib/
  main.dart                      تهيئة التخزين وتراخيص الخطوط وProviderScope
  app/hadith_app.dart            MaterialApp عربي RTL بثيمين فاتح وداكن
  core/
    theme/                       لوحة الألوان (ThemeExtension) والخطوط والثيم
    ui/                          حواف smooth_corner وبطاقات وأزرار عريضة وأوراق سفلية
    storage/                     مخزن محلي فوق SharedPreferencesWithCache، وملح الجهاز
    preferences/                 طريقة التلقي المفضلة (لمس / سماع)
    audio/speech_service.dart    الصوت الآلي للسرد والمأزق فقط
    text/                        الأرقام العربية، وتجزئة ثابتة للبذور
    time/clock.dart              ساعة قابلة للاستبدال في الاختبارات
  features/
    hadith/                      المحتوى: النماذج المولّدة، والمستودع، والمزودات
      data/models/               نماذج غير قابلة للتغيير مولّدة من مخطط واحد
      data/asset_content_repository.dart
      domain/                    عقد المستودع، وحزمة العرض، وصياغة الإحالات
      application/content_providers.dart
    journey/                     مسار القوافل
      domain/                    اللقطة الصرفة، والتقدم، وجدول فتح الفجر
      data/                      حفظ التقدم
      application/               JourneyController (AsyncNotifier)
      presentation/              الشاشة، والمسار المتعرج، والرسام، والعقد، وبطاقة المحطة
    daily_session/               الوِرد اليومي
      domain/                    محرك الترصيع والتلاشي، ومقارنة الروايات، وشجرة الإسناد
      application/               SessionController (Notifier.family) يقود PageView
      presentation/              الشاشة، والمراحل الأربع، وطبقة طالب العلم، والختام
    recitation/                  تلاوة المتن المسجلة والتتبع الصوتي التزامني (just_audio)
    oral_mode/                   مجلس السماع: السرد، والتلقين بالترديد، والمأزق
```

**إدارة الحالة:**
- البيانات غير المتزامنة: `AsyncNotifier` و`FutureProvider`.
- حالة الواجهة: `Notifier` و`Notifier.family`. في Riverpod 3 صار `Notifier` بديل `StateNotifier`، ونُقل `StateNotifier` إلى `legacy.dart`.
- تتصل الطبقات من الواجهة إلى المزودات فالمستودع فملفات JSON، ولا يقرأ ودجت ملفاً مباشرة.

## سياسات ثابتة في الكود

- **الخط الأحمر المعرفي:**
  - لا يولّد التطبيق متناً ولا سياقاً ولا حكماً.
  - كل نص يُقرأ من ملفات JSON الموثقة كما هو.
  - يفحص المستودع سلامة كل حديث مع الفهارس، ويرفض عرضه إن وُجد خلل.
- **الصوت:**
  - الصوت الآلي يقرأ نصوص السرد والمأزق المكتوبة للمنصة فقط.
  - المتن لا يُسمع إلا من تسجيل قارئ متقن (`AudioStatus.recorded` أو `aligned`).
  - التسجيلات لم تُرفق بعد، ويعرض التطبيق ذلك صراحةً بدل قراءة المتن آلياً.
- **بلا عقاب:**
  - لا قلوب ولا شاشات حمراء، ولا يُصفَّر التقدم.
  - الخطأ في الترصيع يهتز بلطف ويعود.
  - السجل المحفوظ الذي تتعذر قراءته يُنقل إلى مفتاح احتياطي ولا يُحذف.
- **قفل الفجر:**
  - وِرد جديد واحد كل يوم يُفتح عند الفجر.
  - حتى يُضاف حساب الفجر لموقع المستخدم (`FajrTimeSource`)، يُعتمد الوقت الاحتياطي في المنهج (05:00) ويُصرَّح به في الواجهة.
- **الخطوط:**
  - خطا Amiri وReadex Pro من Google Fonts مضمنان في `assets/fonts` برخصة SIL OFL، فيعملان دون اتصال.
  - نُسخ Readex Pro الثابتة مستخرجة بأوزانها من الخط المتغير الرسمي.

## البيانات

انظر [docs/data_model.md](docs/data_model.md). المخطط في `assets/data/schema`، والنماذج مولّدة منه، والاختبارات تتحقق من:
- التحويل ذهاباً وإياباً.
- سلامة المراسي.
- أحداث المحطات وبنك العبارات.
- منطق المسار وقفل الفجر.
- محرك التثبيت.

## أدوات المخطط

`tools/schema/spec.py` هو المصدر الوحيد لتعريف النماذج:
- لإعادة توليد النماذج والمخطط بعد أي تعديل فيه: `python3 tools/schema/gen.py .`
- للتحقق من ملفات البيانات: `python3 tools/schema/validate.py .` (يتطلب حزمة jsonschema).
